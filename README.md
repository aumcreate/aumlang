# AumLang – AI Multilingual Translation & SEO

Builder-friendly, SEO-complete AI multilingual translation. One-click page translation that preserves your Elementor and Gutenberg layouts.

- **WordPress.org:** https://wordpress.org/plugins/aumlang/
- **Website:** https://aumcreate.com
- **Support:** support@aumcreate.com

## About this repository

This is the released source of the plugin, exactly as published on WordPress.org — one commit per release, tagged with the version. Bug reports and pull requests are welcome here; fixes are folded into the next release.

## Install

Install from the WordPress plugin directory (Plugins → Add New → search for *AumLang – AI Multilingual Translation & SEO*), or download a release from this repository's tags and upload the ZIP.
